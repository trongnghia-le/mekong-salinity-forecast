# Alternative free sources of observed VMD salinity (checked 2026-11-01)

Goal: fill gaps in the dekadal Smax target (28 NCHMF stations, dry seasons 2015-16 to 2025-26), mainly Dec-Feb,
2016-17 to 2019-20, 2022-23, and the record seasons 2015-16 and 2019-20. This builds on salinity_data.md section 1;
sources already listed there are not repeated unless something new was found.

Evidence labels: **checked** = page or file opened this session; **snippet only** = search-engine text;
**not verified** = not confirmed. "Station-month" = one monthly maximum at one station. All counts are rough.
Sample files are in `data/raw/alt_samples/<source>/` (not to be redistributed).

## Bottom line

- **Best free option: back-calculate prior-year monthly maxima from the comparison column of the bulletins we already
  hold** (row 1). No new downloads; about 230-250 new station-months. These include the gap months Jan-Feb 2020 (record
  season), Mar-Apr 2023 (2022-23 gap), Feb 2024 (Dec-Feb gap), and Jan and May 2016. Each monthly maximum is an exact
  value for one dekad of the month and an upper bound for the other two, so it suits a censored likelihood and
  exceedance checks. It does not give full dekadal series. Check each bulletin's reference month by hand.
- **Second: the PCTT daily reports, Feb-May 2020** (row 2). Daily values at 4 of the 28 stations (Tân An, Bến Lức, Cầu
  Quan, Gò Quao) give ~40 station-dekads in 2019-20, and the same-date 2016 column gives ~40 more in 2015-16. Four extra
  upstream stations come with them. Scraping ~105 pages is cheap.
- **Third: SIWRR season-to-date maxima** (row 4). This is the only free trace of 2016-17 and 2017-18 at ~15-20
  stations, and adds ~8 snapshots in 2015-16. The data are interval-censored, not dekads.
- **Unfillable for free (as dekadal Smax at most of the 28 stations):** all of 2016-17, 2017-18 and 2018-19 (nothing at
  all for 2018-19); Dec-Feb of 2016-17 to 2018-19, 2020-21 (Dec), 2022-23, 2023-24 and 2024-25; 2019-20 dekads
  outside the 2 archived bulletins and the PCTT stations. NCHMF did not publish station bulletins online before
  25/12/2019 (row 8). The 25 missing 2019-20 bulletin files are known by name but archived nowhere we could reach.
  The routes left are NCHMF's reply to the permission request (ask for these files by name) or the paid KTTV data
  service (salinity_data.md 1n).
- Licences: none of the new sources states reuse terms except SIWRR (credit). Use the values for scoring; publish code
  and scores only, as for the bulletins.

## Method notes (reproducible)
- Wayback CDX was queried one request at a time, ≥12 s apart, with back-off on "Temporarily Offline". Each empty
  result had a positive control through the same query form (e.g. thoitietvietnam.gov.vn/upload/thuyvan2/2020/2/ →
  3 captures; 2019/ → 0).
- Common Crawl: `index.commoncrawl.org/<crawl>-index?url=...&filter=~url:(?i).*(xam-nhap|han-man|xam-man|xman|xmnb|xmtb|tvtb).*`;
  positive control CC-MAIN-2024-22 kttv.gov.vn → 3 salinity posts.
- PCTT: 10th and 20th of each Dec-May probed with four slug variants (d-m-yyyy, dd-mm-yyyy, ...). HTML text was searched
  for "Trạm đo mặn"; if absent, the attachment text was searched too.
